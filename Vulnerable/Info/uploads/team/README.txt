TEAM PHOTOS DIRECTORY
=====================

Place team member photos in this directory.

Naming Convention:
------------------
Name each photo file using the team member's code number.

Example:
- 21001646.jpg (for Omar Magdy Abdallah ElKhazendar)
- 21033693.jpg (for Kerelos Zakarya Tadros Botros)
- 21065393.jpg (for Ziad Mahmoud Ahmed Abdelgwad)
- 21007626.jpg (for Ahmed Mourad Mohamed Anwer)
- 21049580.jpg (for Ahmed Mohamed Ashri Mourad)
- 21117329.jpg (for Abdelrahman Ashraf Mohamed Abdo)

Supported Formats:
------------------
- .jpg
- .jpeg
- .png
- .gif

Note: The code will automatically look for .jpg files. If you use a different format, 
you may need to update the code in team.php.

If a photo is not found, a default user icon will be displayed.
